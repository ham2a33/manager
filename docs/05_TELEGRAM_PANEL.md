# 1. Overview

Telegram Panel — основная административная панель AI Manager.

Через Telegram владелец компании полностью управляет системой.

Telegram Panel должна быть простой, быстрой и не требовать обучения.

Все основные действия должны выполняться максимум за 2–3 нажатия.

---

# 2. Авторизация

Вход осуществляется через Telegram.

После команды:

/start

Система проверяет:

- существует ли пользователь;
- есть ли компания;
- есть ли активная подписка.

Если пользователь новый:

1. Создать аккаунт.
2. Создать компанию.
3. Открыть мастер первой настройки.

# 7. Ручной ответ

Если пользователь нажимает "Ответить"

Telegram ожидает сообщение владельца.

Следующее сообщение автоматически отправляется клиенту.

После отправки:

Владелец возвращается в карточку диалога.

---

# 8. Передача AI

Если владелец закончил общение.

Нажимает:

"Передать AI"

Conversation Status:

Следующие сообщения снова обрабатывает AI.

# 21. Основные правила

1. Telegram — единственная панель управления.

2. Все действия выполняются через кнопки.

3. Пользователь не должен вводить команды вручную.

4. Все изменения подтверждаются системой.

5. Любое действие можно отменить.

6. Все ошибки отображаются понятным языком.

7. Интерфейс должен быть быстрым и минималистичным.

8. Telegram не хранит бизнес-логику — он только взаимодействует с Backend API.

9. Все данные загружаются через Backend.

10. Telegram должен быть готов к замене на Web Dashboard без изменения серверной логики.
